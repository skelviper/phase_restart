# 全基因组等位基因拆分计划

> 取代 `PLAN-allele-split.md` 的单染色体版本（已删除）。

**目标（一句话）**：用 P9016 一个细胞的**全部接触数据**（无 phase / SNP / 参考信息），
一次性拟合出 **40 条轨迹**（20 条染色体 × 2 个拷贝）在**同一个细胞核体积**里的 3D 结构，
然后和 `data/P9016.1m.3dg.gz` 比。

**不再做**：信息存在性实验、训练/测试折、held-out 判据。

---

## 0. 已测清的可行性（不是估计，是实测）

| 项目 | 实测结果 |
| --- | --- |
| 全基因组 1 Mb，40 条 track（5,250 beads），1.7M 接触 | **0.375 s / 迭代**；1000 次迭代 **375 s（6.3 分钟）** |
| 同上 2 Mb（~2,626 beads） | 0.118 s / 迭代；1000 次 **118 s** |
| 同上 5 Mb（~1,050 beads） | 0.022 s / 迭代；1000 次 **22 s** |
| 收敛性（用相干标签） | 1 Mb 在 1000 次迭代内 **RMS_force = 0.0010，已收敛** |
| `-I FILE` 多分辨率热启动 | 支持，按位置重采样（`hk_bmap_pos2bid` + 链内插值）。实测 5→2→1 Mb 可用，但比冷启动略慢，**默认不用** |
| 排斥力是否跨染色体 | **是**。`update_force` 的 `FORCE_REPEL` 只有距离判据、没有染色体判据；backbone 力才限染色体内。引擎提供共享 excluded volume，**没有显式有限半径核球或径向 confinement 势**。 |
| inter 接触 | 直接作为 contact 力参与摆位，与 cis 同等对待 |

**操作陷阱（已踩）**：`-b` 选项**在解析时就执行 FDG**，所以 `-n` 必须写在 `-b` 前面，
否则不生效（`-b1m -n 3000` 只跑 1000 次，`-n 3000 -b1m` 才跑 3000 次）。
引擎不可改（`native/hickit/PROVENANCE.md`），只能包装。

## 1. 必须先说清楚的一件事：目标函数的对称群

这不是"信息在不在"的问题，是**目标函数本身的性质**，它直接决定算法怎么写。

记第 c 条染色体的两份轨迹为 `X_c, Y_c`，半差场 `u_c = (X_c − Y_c)/2`，中点 `Z_c = (X_c + Y_c)/2`。

- **cis 接触**有 1,135,454 条同染色体记录。98.2% 是历史评估中**两端均定相的 intra
  子集**里同拷贝的比例（342,911 vs 6,114），不能当作全体 cis 的训练分母或固定参数；简化的
  同拷贝和 `λ = s ( d(X_i,X_j)^-a + d(Y_i,Y_j)^-a )` 对 `u_c` 是偶函数。
- **trans 接触**（不同染色体）：观测计数是四种拷贝组合之和
  `λ = s [ f(X_c,X_d) + f(X_c,Y_d) + f(Y_c,X_d) + f(Y_c,Y_d) ]`
  —— 把 `u_c → −u_c` 只是把这四项重排，**和不变**。

**结论：整个似然对任意子集的 `u_c → −u_c` 精确不变，简并度 2²⁰。**

三个直接后果：

1. **全基因组 + inter 接触不会自动解决符号问题。** 它给出的是物理上有意义的整体几何
   （染色体领地、核内球状堆积、染色体间相对摆位），但不会令输出自动与参考 3DG 共用
   全局坐标框架。平移、旋转和尺度仍是各自结构的自由度；报告按尺度无关读数或独立中心化，
   不把独立 frame 的相似外观解释成已全局对齐。
2. **每条染色体的 A/B 全局标号是规范自由度**，测不到也不影响任何读数。
   跨染色体比较时按几何选最佳交换即可（沿用现有政策）。
3. Stage 1 在 chr1 的**预注册扰动**上实测到特定 fragment-swap 会降低相应的无标签 readout；
   这是该仪器在该条件下的敏感性，不是全局可辨识或任意拼接都必然失败的证明。L2 仍要问 blind
   方法能否产生单一连贯的 `u_c` 场。

**驻点边界**：偶性只保证 `u = 0`（两份完全一样 = 塌缩）是一阶驻点；它不决定曲率、局部
稳定性或任何求解器是否能逃逸，这些必须实测。已有证据仅是当前 hard-assignment + FDG loop 的
随机初值未逃逸（F6），不是对所有非线性方法的否定。S2 若实施，初值与接受规则仍必须只用
无标签似然。

## 2. 判据（对照参考结构，评估侧专用）

方法输出 `X, Y ∈ R^{N×3}`（当前 3 Mb 指标网格 N = 2,585 个 1 Mb bin，全部染色体；全坐标
文件可另含 0--2 Mb beads，不能把两者混为同一尺寸）。

| | 是什么 | 备注 |
| --- | --- | --- |
| **R1** 逐接触准确率 | 用参考标签的同拷贝 cis 记录，排除同 bin / 网格外记录 | 每条染色体先在四条距离轨迹的共同 finite 非对角 bin pair 上，以 `(rho(a,mat)+rho(b,pat))` 对比交换项固定几何 gauge；`phase0=pat`、`phase1=mat`。候选、参考 ceiling、oracle-fit ceiling 同分母；几何打平取两方向均值，不用真标签破平局。 |
| **R2** 结构一致性 | 四个 `Spearman(D_copy,D_ref)` 在同一共同 finite 非对角 pair 集上组成 2×2 表 | contrast 由同一几何 gauge 给出。single consensus 没有双拷贝 contrast，标为不适用，仅保留单轨迹对 mat/pat 的结构基线。 |
| **R3 片段一致性（主判据）** | 从 3 Mb 指标网格开始的 20 Mb 片段；每段使用两份候选和两份参考 | 报可判片段分母、`frac_consistent` / `longest_run` / **`n_walls`**。局部 score 打平或缺失片段不计入分母，且会断开 run/wall；`frag_start_mb` 是旧网格 offset，物理起点另报 `frag_start_bp`。 |

超参（`a`、尺度、正则权重）**用无标签计数似然选**，不用 R1/R2/R3 选。R1/R2/R3 只用于报告。

## 3. 方法阶梯

### S0 — 三个参照点（半天）
| 候选 | 做法 |
| --- | --- |
| `consensus` | 20 条 track、全接触（含 inter）单结构拟合。**塌缩基线**，必须打败的对手 |
| `random` | 随机 50/50 硬分配 → 40 条 track FDG |
| `oracle` | 真 phase 标签分配（只用完全定相记录，349,025 cis + 146,996 trans）→ 40 条 track FDG。给 `ceil_ours` |

每一次 40-track 拟合内部的轨迹都在同一核内体积；这不等于它与参考或另一独立拟合共用
坐标框架。S0 同时验证引擎在 40 track 下正常；跨结构报告使用上述 gauge、秩相关或独立
中心化/单位 RMS 诊断。

### S1 — 单结构共识 `Z`（并入 S0）
`Z ∈ R^{N×3}`，无标签。是 S2 的几何骨架。

### S2 — 半差场 `u` 的非线性拟合（**主力**）
未知量 `u ∈ R^{N×3}`（当前指标网格 7,755 个坐标分量），`X = Z + u`，`Y = Z − u`。

目标函数（Poisson 对数似然，用**全部**接触）：

```
对同染色体记录，以仅由无标签计数拟合的 nuisance 参数 `p_cis` 表示同拷贝混合权重：

λ_cis = s_cis [ p_cis/2 · ( f(X_i,X_j) + f(Y_i,Y_j) )
              + (1−p_cis)/2 · ( f(X_i,Y_j) + f(Y_i,X_j) ) ]

对跨染色体记录，四个拷贝组合**等权**求和：

λ_inter = s_inter/4 · [ f(X_c,X_d) + f(X_c,Y_d) + f(Y_c,X_d) + f(Y_c,Y_d) ] ,
f(a,b) = |a−b|^-a

L(u) = Σ_p [ λ_p − c_p log λ_p ]  +  正则项
```

**四项都必须保留。** F1/F2 的带标签计数仅是评估侧的历史事实，不能写进训练参数或初值。
`p_cis` 不作为已知常数使用，只能由无标签计数似然估计或按预先规定的无标签规则处理。
跨染色体没有 `p_inter`：人为学习 same-haplotype 权重会破坏每条染色体独立的 2²⁰ gauge，
与目标函数对称性冲突。

**不需要硬分配，不需要 EM**。解析梯度，纯 numpy，每次迭代秒级，可以跑大量初值。

**初值 `u₀`（这是全计划最关键的一步）**，三种都跑：

1. **残差反演初值（新，最有希望）**：
   `u=0` 时拟合 `Z` 得到预测 `λ₀`。残差 `r = c − λ₀`。由二阶展开
   `λ ≈ 2 s d̄^-a [1 + (a(a+1)/2)(δ/d̄)²]` 反解出 `|δ_ij| ≈ d̄ · sqrt( 2 r / (a(a+1) λ₀) )`。
   这给出**每条 bin 对的 |δ| 幅度约束**。然后解**非线性**相位恢复得到 `u₀`
   （注意：F12 失败的是**线性化**版本，`|δ|/d̄ = 0.51` 使线性化无效；非线性版本没试过）。
2. **谱初值**：线性化算子的前几个特征向量（F12 只把它当过**解**，没当过**初值**）。
3. **随机小扰动**：多种子，作为对照；预期最弱。

**正则项**：弱排除体积（防两点重合）+ 沿链平滑先验。S3 的 FDG 提供共享 excluded volume 与聚合物 proposal；若需要有限核半径，必须另行定义和校准。

**优化日志与停止规则**：只记录无标签似然、数值收敛和预先定义的约束诊断。R1/R2/R3 和参考
只能在坐标写盘并哈希后用于报告，不能挑初值、早停、接受候选或选择超参。

### S3 — 用 native FDG 把几何拉回真实聚合物（共享 excluded volume）
1. 用 S2 的软后验把接触预算按**整数**分配到 40 条 track（保总数不变）；
2. 写 40-track pairs 文件（cis + trans 全部），跑 `hickit -n 1000 -b1m`（**6 分钟**）；
   FDG 的跨染色体排斥提供共享 excluded volume 和染色体领地，但不是有限核半径约束；
3. 用无标签计数似然接受/拒绝；回 1，最多 3 轮。

**这不是 F6 失败的那个硬 EM**：初值已不是塌缩点，且每轮有明确的接受判据。

### S4 — 全基因组符号同步（只在 S2/S3 出现"局部好、全局跳"时启用）
把染色体切重叠窗口，每窗独立跑 S2，然后在窗口间同步标号：
- 重叠区几何贴合度（窗口之间）；
- trans 接触只提供空间摆位和几何约束，**不能**同步不同染色体的 copy 身份；对任意一条
  染色体的全局 A/B 交换，四项和不变；
- 链连续性。

Stage 1 已确认无标签计数判据能把全局一致排在预注册错接之前 —— 这是**现成资产**，
不需要重新验证。

## 5. 报告规范（沿用，不放松）

1. R1 必须带同分母的 `ceil_ref` 和 `ceil_ours`，以及实际 record denominator、网格外/缺失/tie 计数；
2. 主判据是 R3 不是 R1；
3. 每个结果都带 `consensus`（塌缩）和 `random` 两个对照；
4. 报**所有**跑过的初值/变体，不只报最好的；多初值一致性本身是结论的一部分；
5. 说明支持 L1 / L2 / L3 中的哪一个；S2–S4 成功支持的是 **L2**；
6. 参考结构是**上限**不是真值；
7. 每个全基因组拟合内部共享一个核内体积，但不自动与参考共用坐标 frame。报告图采用独立
   中心化/单位 RMS 或明确的后验显示变换，不能把它当作评估或全局对齐证据。

## 6. 数据范围

- **用**：全部 1,703,888 条接触（1,135,454 cis + 568,434 inter），不分割，不筛标签。
- **inter 接触的作用**：空间摆位（染色体领地、核内球状堆积、染色体间相对位置）及可能的
  几何条件数改善；它不携带可同步跨染色体 copy 身份的信号，也不打破 2²⁰ gauge。
- **chrX**：方法和其它染色体一样跑。它定相率低（15.3%）只影响**评估精度**，不影响方法。
  单独报，并标注其 `ceil_ours` 更低。
- **绝不使用**：`phase0`、`phase1`、`phase_prob*`、参考 3dg —— 只在坐标写盘并哈希之后
  由评估侧读取。
