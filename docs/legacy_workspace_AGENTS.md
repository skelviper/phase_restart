# AGENTS.md

## 任务与当前边界

从 `data/P9016.pairs.gz`（去掉单倍型列）重建 P9016 小鼠单细胞的二倍体三维结构：20 条染色体、40 条拷贝轨迹，在一个共享核体积中联合拟合全部 **1,703,888** 条接触（染色体内与染色体间），并诚实评估仅凭接触能恢复多少真实单倍型拆分。参考结构 `data/P9016.1m.3dg.gz` 只能在候选坐标写出并完成哈希后用于评估。

工作范围是全基因组，不是逐染色体拟合。染色体间接触用于空间放置（染色体空间分区和核内装箱），但不用于单倍型准确率。第 1 阶段（Stage 1）的逐染色体评估检验已完成，不是当前关键路径。详细历史、数值和阶段时态见 `docs/PROJECT_CONTEXT.md`；证据原表见 `docs/MEASURED_FACTS.md`。

三项结论必须分开：

| 结论 | 当前状态 |
| --- | --- |
| **L1**：混合接触含有与两套结构差异相关的可预测信号 | chr1 支持；chrX 证据边缘，具体区间与分母见 `docs/PROJECT_CONTEXT.md`。 |
| **L2**：沿整条染色体的一致拷贝身份可恢复 | **尚未证明**。评估工具能惩罚全局错接，不代表盲方法已经找到一致拆分。 |
| **L3**：任何无 SNP 方法都不能工作 | **已撤回**。现有证据只否定当前循环中的特定方法，不是否定非线性求解器这一类。 |

L1 不推出 L2。不得把局部正确、全局错接或 oracle 上限写成“拆分已恢复”。

## 科学隔离与数据边界

- 训练侧不得读取 `phase0`、`phase1`、`phase_prob00..11`、其派生物或参考 3DG。`run.py prepare` 必须写出恰好 7 列；加载器必须拒绝 `#columns` 含 phase 字段的文件。
- 只有候选坐标写出并完成哈希后，评估器才可读取 phase 列和 `data/P9016.1m.3dg.gz`。
- `copyA`/`copyB` 是拷贝标签的规范自由度；跨拷贝指标须按几何为每条染色体选择最佳互换，并写明策略。
- 染色体间接触的同/异单倍型计数为 `70,558`/`76,438`，没有母源/父源标签信号；它们仍是空间放置的几何约束。这两句话必须同时保留。
- 计数目标具有精确的 `2^20` 对称性：任意染色体的 `u_c -> -u_c`（`u_c = (X_c - Y_c)/2`）不改变 `lambda`。每条染色体的 A/B 全局标签是规范自由度，加入染色体间接触也不破坏对称性；方法必须显式离开 `u = 0`。
- 当前 Reconstruction V1 用全部接触的无标签计数似然选择候选，不使用训练/测试拆分；参考 3DG 只用于报告 R1/R2/R3，不能选择超参数、停止或选择候选。
- 20 条染色体是同一细胞中的 20 个关联测量；bootstrap 区间描述该细胞内的技术/结构变异，不是生物学重复。
- “全数据计数目标”与旧 Stage 0/Stage 1 的留出判据必须分开叙述；旧协议只用于冻结基线和评估检验。历史适用阶段见 `docs/PROJECT_CONTEXT.md`。

## 更正后的协议

1. 基因组坐标必须数值比较；字符串比较曾丢掉 `147,005 / 1,135,454`（12.95%）条染色体内接触。
2. 数据折不得由基因组距离函数产生；旧 `(i*7919 + j*104729) % 2` 等于 `(i+j) % 2`，会把同区间对全部送入 `test`。使用数值 bin 对的混合哈希，旧基线使用训练/验证/测试折。
3. 距离指数等超参数只能在 `validation` 折选择，不得在 `test` 折选择。
4. 同区间（零距离）对从结构指标排除并单独报告：`438,774 / 1,135,454`（38.64%），不含结构信息。
5. 两拷贝比较必须规范不变：对候选结构及其标签互换版本与 oracle 及其互补版本取均值，或使用对标签互换不变的 `rewire` / `splice`。原生引擎的拷贝标签不对称曾使 chr1 留出 rho 改变 `0.0220`。
6. `hickit -s` 只是优化初始化重复，不是独立重复；`-s` 必须置于 `-b` 前才能实际设随机种子，独立拟合仍须改变数据。
7. `hickit -b` 在解析时拟合；`-n` 必须置于 `-b` 前，例如 `-n 3000 -b1m`。
8. 当前 V1 没有训练/测试拆分；所有接触拟合每个候选，超参数只由无标签计数似然决定，参考结构仅作评估上限。

## 报告底线

1. 逐接触准确率必须同时给 oracle 上限。
2. oracle 只能由标签完整的接触构建，不得使用标签不完整的 oracle。
3. 两结构增益必须给随机拆分、共识、逐染色体胜出数和 bootstrap 置信区间。
4. 不以 `1 - rho(dA, dB)` 衡量结构恢复；使用 `matched-minus-swapped`，并给 `u = 0` 与 `random-u` 对照。
5. 每次 E-step 带符号断言；真结构硬分配应超过 `0.55`（已测 `0.6597`）。
6. 结构尺度未校准，按 rank 或 Procrustes 比较；拷贝内相关高不等于同源拷贝恢复，必须报告综合读出。
7. 保留历史时态和适用阶段。冻结协议、`source_snapshot`、`archived020` 和第三方文档不改字节；中文阅读版本由 `docs/zh_archive/README.md` 索引映射。
