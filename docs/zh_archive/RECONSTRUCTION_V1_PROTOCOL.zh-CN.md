# Reconstruction V1 观测协议

## 状态与范围

**状态：prototype / calibration pending（原型 / 等待校准）。** 本文件冻结
P9016 Stage 2 计划的第一版连续观测模型原型。它不是已完成的重建、不是生物学恢复结论，也不授权运行正式 P9016 优化。在任何正式拟合、参数扫描或参考侧评估之前，必须先获得上游阶段发布许可。

该原型在一个共享的无量纲核球中，为每条染色体重建两条无标签轨迹。它有意与现有 native-FDG 和 `run.py` 路径分开。训练侧不读取 phase 列、phase 概率、参考 3DG，或任何一方的衍生物。

观测单位是基因组 bin 对的聚合计数 `C_ij`。同一 bin 对上的重复原始记录会相加为同一个非负整数计数。初始化差异和合成采样差异都只是技术变异，不是生物学重复。

## 坐标与网格约定

在分辨率 `B` bp 下，表头长度为 `L` 的染色体有 `ceil(L / B)` 个位点，bin 索引为 `0, ..., ceil(L / B)-1`。bin `b` 表示半开基因组区间

```text
[b * B, min((b + 1) * B, L)) .
```

末端不完整 bin 也保留。真实记录的端点只有在 `0 <= pos < L` 时有效，并按冻结项目约定映射为 `bin = pos // B`。完整网格从基因组 bin 零开始，不继承旧版 3 Mb 评估偏移。表头中没有端点的 bin 仍保留在训练网格中。坐标导出记录 bin 起点 `b * B`，包括末端 bin。

按原始 SNP-free `#chromosome` 表头顺序，把各染色体的局部 bin 串接为 `N_loci` 个全局位点。聚合结果保存显式的 `track -> (chromosome_index, chromosome_name, copy_index)` 映射：按该表头顺序依次为 `c01a`、`c01b`、再到 `c02a`、`c02b`，以此类推。调用方不得通过按字典序排序轨迹名称来推断染色体身份。今后的坐标导出必须为每个完整网格 bin 写出两份拷贝，包括旧版 3 Mb 偏移之前的 bin、没有端点的 bin 和末端不完整 bin。对于缺少珠子的旧版 native 坐标，必须通过预先声明的插值/端点填充流程并加入预先规定的小幅非零扰动来扩展；绝不能为了匹配旧坐标清单而丢弃记录。

结构可用集合是完整的无序集合

```text
E = { (i, j) : 0 <= i < j < N_loci } .
```

它包含染色体内和染色体间配对，也包括零计数配对。实现必须根据表头构造 `E`，不能根据观测记录构造。每个分辨率都要断言原始记录严格守恒：

```text
M_all = M_diag + M_cis_offdiag + M_inter
      = 对冻结的 P9016 文件为 1,703,888。
```

`M_diag` 统计两个端点落在同一基因组 bin 的 cis 记录；`M_cis_offdiag` 和 `M_inter` 是另外两类。对 `C_ij` 聚合后的总和，必须分别严格等于对应的原始预算。

## 坐标与核球约束

对于位点 `i`，两份拷贝为 `X_i, Y_i in R^3`。优化器负责无约束变量 `y`，并对每个物理珠子独立应用

```text
x = y / sqrt(1 + ||y||^2) .
```

因此每个坐标都满足无量纲核球中的 `||x|| < 1`。尺度没有校准，绝不能描述为微米。对于输入坐标梯度 `g_x`，解析拉回为

```text
g_y = r^-1 [ g_x - x (x dot g_x) ],  r = sqrt(1 + ||y||^2) .
```

两份拷贝共同移动；没有冻结的共识 `Z`、径向硬势或无约束坐标导出。

## 固定暴露量与有界接触核

对于每个位点，令 `endpoint_count_i` 统计映射到该处的每条原始记录的两端，包括同 bin 记录。拷贝共享的固定暴露量为

```text
e_i = sqrt(endpoint_count_i + 10) / mean_full_grid(sqrt(endpoint_count + 10)).
```

它不会被优化。这是一个无标签工作假设，不是已经把可见性与几何分离的结论。它可能混合捕获、可比对性、可见性、bin 容量和真实空间信号。均匀暴露量和按 bin 长度的暴露量属于未来敏感性分析，不是本阶段自动搜索的参数。phase 信息不得用于校准暴露量。

在某个分辨率层、半径为一的球内包含全部 `2 * N_loci` 个物理珠子时，定义

```text
l0 = (2 * N_loci)^(-1/3)
r0 = 2 * l0
epsilon = 1e-6
K(d) = epsilon + (1 - epsilon) * (1 + d^2 / r0^2)^(-2).
```

尾部指数为四。`K` 在零点有限；但同 bin 记录仍不作为几何项使用。

## 计数模型

对于每个可用配对，用四种拷贝距离定义其 rate。对于 cis 配对，

```text
rate_ij = e_i e_j * [
    p / 2       * (K(X_i, X_j) + K(Y_i, Y_j))
  + (1 - p) / 2 * (K(X_i, Y_j) + K(Y_i, X_j))
].
```

对于 inter 配对，

```text
rate_ij = e_i e_j / 4 * [
    K(X_i, X_j) + K(X_i, Y_j) + K(Y_i, X_j) + K(Y_i, Y_j)
].
```

整个基因组只有一个 cis 干扰项 `p`。它初始化为 `0.75`（该值预先选定，与历史 phase 比例无关），并用无约束 `q` 参数化：

```text
p = 1e-4 + (1 - 2e-4) * logistic(q).
```

不拟合 inter same-haplotype 干扰项。加入归一化目标的先验为

```text
-1e-4 * log(p * (1 - p)).
```

它是对称的，只对有界端点施加很弱的排斥。

对于 `g in {cis_offdiag, inter}`，固定观测组总数 `M_g`。令 `R_g = sum_{(i,j) in E_g} rate_ij`。候选相关的条件计数负对数似然为

```text
NLL_cond = sum_g [ M_g * log(R_g) - sum_{(i,j) in E_g} C_ij * log(rate_ij) ].
```

这是对每个组的尺度剖面化后的独立 Poisson 似然，等价于条件总数的多项式形式。它有意省略与候选无关的条件计数阶乘常数

```text
sum_g [ -log(M_g!) + sum_{(i,j) in E_g} log(C_ij!) ].
```

代码会记录这个省略量以供审计；`R_g` 中绝不能把零计数配对当作不存在。

同 bin 计数作为单独的、非结构性的逐 bin 饱和 Poisson 干扰项层保留。对每个对角 bin，将其干扰项均值剖面化为 `mu_i = C_ii`；不假设共享的对角暴露量或几何模型。其完整的、与候选无关的 NLL 为

```text
NLL_diag = sum_i [ C_ii - C_ii * log(C_ii) + log(C_ii!) ],
```

其中零计数项定义为零。这一层没有坐标梯度或 `p` 梯度。它只结合原始计数预算进行报告；同一分辨率的所有候选都有相同的逐 bin 干扰项层，绝不能用它宣称结构改进。它也不能代入 `K(0)`，或被静默丢弃。

归一化计数贡献为

```text
(NLL_cond + NLL_diag) / M_all.
```

同一分辨率下比较的所有候选具有相同的参数维度、固定先验和 `M_all` 分母。不同分辨率的绝对 NLL 不得比较，因为它们的网格和剖面化计数层不同。

## 联合聚合物先验

完整原型目标由归一化计数项、`p` 先验和三个坐标项组成。以下都使用上面的 `l0`，并分别报告。

```text
bond = mean_tracks_and_adjacent[
    hinge(0.75 - d/l0)^2 + hinge(d/l0 - 1.25)^2
]
weight_bond = 1

repulsion = sum_{all unordered physical bead pairs}
    hinge(1 - d/(0.7*l0))^2 / (2*N_loci)
weight_repulsion = 1

bend = mean_track_interior[ ||x_(i+1) - 2*x_i + x_(i-1)||^2 / l0^2 ]
weight_bend = 0.01.
```

排斥包含 `2*N_loci` 个物理珠子之间的所有配对：每个无序位点配对的四种拷贝组合，以及每个位点处的同源配对。键长项 bond 和弯曲项 bend 只在单条染色体轨迹内计算。没有额外的硬排斥、固定的共识坐标或静默的跨染色体例外。

## 优化与实现检查

原型使用 SciPy L-BFGS-B，把 `y` 和 `q` 上的优化作为无约束 L-BFGS，并为接触似然、`p`、bond、repulsion、bend 和球面拉回提供解析梯度。它按分块扫描 `E`（默认 65,536），不构造稠密的 `(N, N, 3)` 坐标数组。计数计算先对每个组做一遍 rate 总和和观测 log-rate 项，再做第二遍梯度计算。repulsion 也按物理配对分块扫描。

代码提供面向未来运行的 40 条轨迹坐标导出接口，但本原型不修改 `run.py`、native FDG、已有结果目录或正式命令行行为。整数接触 FDG 不属于这条主要连续优化循环。L-BFGS API 记录真实的目标/梯度调用次数和耗时。只有当优化器 theta 与最近一次解析梯度 theta 完全相等时，回调才复用 value/components 缓存；绝不使用容差匹配。可选的、由调用方拥有的 `checkpoint_hook` 会在声明的间隔（请求时默认每 10 个已接受迭代）接收可安全复制的 `theta`、坐标、components、计数和耗时快照。API 本身不写检查点。

## 可辨识性、局限与报告边界

整条染色体的拷贝交换是精确规范对称性。此外，在 `p = 0.5` 时，bin 级别的 A/B 局部交换只会置换四个数据项，因此接触数据似然无法区分它们。链和其他聚合物先验可能因这种局部交换而改变。因此，一条看起来连贯的轨迹本身不能证明接触数据恢复了长程拷贝身份。

报告拟合的 `p`、其有界参数化、各组成损失、候选初始化，以及 `p = 0.5` 的局部交换诊断。没有单独冻结的评估，不得使用 `p` 或收敛目标声称 L2。

已知局限包括：单一全局 cis 混合权重；可能与几何混淆的固定暴露量；除有限核之外没有基因组距离干扰项；没有校准的物理长度；只有一个生物细胞；以及包含塌缩/对称驻点的非凸目标。本协议既不声称 `u = 0` 稳定，也不尝试只反演正残差。

不得利用真实 P9016 似然对模型容量、正则化、核函数、暴露量或初始化系列进行无限搜索。正式复杂度和正则化必须先获得上游批准的、预先规定的预算和合成校准。参考结构绝不能选择这些值。

## 计划中的合成校准（尚不是生物学结果）

合成真值只存储在评估侧，并只在评估侧使用。训练输入只含无标签合成接触。除非明确标为微型数值测试样例，每个条件都使用 20 条染色体、40 条轨迹、相同的完整网格构造和与拟议真实分辨率相同的总记录核算。

1. **无噪声期望计数：** 构造明确标记为 `synthetic_expected` 的完整网格副本，其中包含分数期望质量。这是条件交叉熵数值校准，不是把分数观测当作 Poisson 概率模型；因此不定义或使用计数阶乘常数。核验目标/梯度一致性，而不是 P9016 生物学。
2. **带已知采样噪声且使用已知合成暴露量：** 在定义良好的校准中使用合成生成暴露量，按预先规定的计数过程抽样，并报告所有初值和组成值。
3. **真实稀疏度与捕获模型错设：** 使用生产的 observed-endpoint 暴露量公式重复运行，同时让合成捕获/可见性偏离该公式。量化错设敏感性，而不是根据真值选择最佳模型。
4. **两拷贝相同的阴性对照（两级）：** 第一，使用精确 `u = 0` / 共址拷贝，只作为数据项代数和有限值控制。它与物理珠子排斥先验冲突，因此不要求、也不预期完整 MAP 拟合保留重合珠子。第二，使用具有生物学可解释性的阴性对照：每条染色体的两份拷贝内部形状相同，但可通过刚性平移在球内分开。预期没有可报告的形状差异或拷贝身份信号；评估侧 R2 contrast 和 R3 必须报告适当的 tie/unavailable 状态。仅仅把两份物理拷贝分开不构成阴性对照失败。

校准报告会在所有候选旁边给出拷贝差异诊断和似然噪声增益，但两者都不用作恢复分数。合成期望计数对象必须显式声明其 count mode 和 exposure mode。定义良好的条件使用已知合成暴露量；错设条件使用生产的 observed-endpoint 公式。其分数分组总数以声明的严格容差检查，不得整数化。该 API 与原始加载器分开：真实 SNP-free 路径仍保持精确整数和精确端点守恒。

数值验证与生物学恢复是两回事。稠密与分块等价性、有限差分梯度、有界坐标、计数守恒和短程合成目标下降，只能证明原型按规定在内部实现。它们不能证明盲测 P9016 恢复、L1 或 L2。

## 计划中的正式顺序

两个未来的无 phase 初始化已冻结在 [`RECONSTRUCTION_V1_INITIALIZATION.md`](RECONSTRUCTION_V1_INITIALIZATION.md) 中。该文件记录已批准的 S0 014 来源哈希、完整网格扩展、非零扰动和热启动政策；本观测协议不重复或修改这些内容。计划的分辨率顺序为 5 Mb 到 2 Mb 到 1 Mb；两种初始化都到达 1 Mb，保留所有候选，最终排序使用相同的完整 1 Mb 无标签计数似然、固定先验和参数维度。本文件不授权运行这些实验。
