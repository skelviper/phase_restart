# 后续应用实验：多拷贝与稀疏 SNP 辅助重构

## 记录目的与状态

用户在阅读 V1 联合重构方法后明确提出：以后开展两个应用方向的相关实验，先在工程中记录。本文为实验待办和设计起点，不是已冻结协议或已完成验证；本次只记录，不启动实验或修改当前训练入口。

当前参照是 `020` 的连续联合坐标拟合：有限距离核、混合接触计数目标、聚合物 prior，以及坐标与 cis 混合参数的联合优化。当前实现固定每条染色体两个拷贝，训练严格 SNP-free。两个方向都需要独立协议、实现和校准，不能用当前二倍体结果直接宣称可恢复。

相关文档：[V1 观测协议](RECONSTRUCTION_V1_PROTOCOL.md)、[初始化协议](RECONSTRUCTION_V1_INITIALIZATION.md)、[运行协议](RECONSTRUCTION_V1_RUN.md)。实际 020 配置与保存的代码快照是该次运行的依据。

## 方向一：非整倍体、三倍体及其他已知多拷贝结构

### 问题与目标

从无拷贝标签的混合接触中，联合重构具有不同染色体拷贝数的结构。优先研究已知拷贝数；同时推断未知拷贝数是单独的后续问题。

例子：chr1 有三个拷贝，chr2 有两个。chr1 内两个位置有 3×3=9 种来源；chr1–chr2 接触有 3×2=6 种来源。

### 模型扩展起点

- 用显式 chromosome/copy/position 映射替代固定双 copy 轴，每条染色体维护指定数量的连续轨迹。
- 保留对未知来源求和的观测模型：`rate_ij = e_i e_j sum_ab w_ij_ab K(||x_i_a - x_j_b||)`。
- 对具有 k>1 个拷贝的同染色体 pair，可先考虑同拷贝每项权重 `p/k`、跨拷贝每项 `(1-p)/(k*(k-1))`。这是交换对称的工作假设，尚未决定采用；k=1 必须单独定义，不应机械代入。
- 跨染色体均权混合可作为起点；明确 exposure 是否与 copy 数量、容量有关，以及各接触组的总量和归一化。
- 链约束按实际 track 定义；体积、排斥和距离尺度随物理 bead 总数的规则需要校准。
- 评价允许整条染色体的 copy permutation，并报告局部身份一致性及不可辨识情况；不能直接沿用二拷贝 swap 指标。

### 最小验证实验

1. 先用已知 copy 数量的合成数据：二倍体回归基线、仅一条染色体三体、全三倍体。
2. 预先控制接触预算/稀疏度与初始化预算；区分固定总测序深度和随 copy 数增加深度两种比较。
3. 比较结构相似、copy 特异差异、沿染色体身份一致性及初始化稳定性；合成真值仅用于评估。
4. 包括 copy 内部形状相同但空间分离的负对照。物理分离本身不代表差异形状恢复。

### 后续问题与边界

- 未知 copy 数需要额外的模型选择与观测总量/覆盖模型，不能以增加链后训练 loss 下降作为 copy 数证据。
- 局部 CNV、缺失、重复与重排需要定义分段 copy 数和链拓扑，先与整条染色体非整倍体分开研究。
- 更高 copy 数意味着更多来源歧义；数学可扩展不等于给定数据深度下可恢复。

## 方向二：少量 SNP 标签辅助的联合重构

### 问题与目标

针对 SNP 稀少的样本，同时利用全部无标签接触和少量可靠的单倍型标签。目标是让无标签接触提供空间约束、标签帮助确定 copy 身份，并量化相对完全 SNP-free 拟合的收益。

### 模型扩展起点

对一条二倍体接触，根据标签限制或加权潜在来源：

| 标签信息 | 可靠标签下相容的来源 |
|---|---|
| 两端未知 | AA、AB、BA、BB |
| 第一端 A，第二端未知 | AA、AB |
| 两端 A | AA |
| 第一端 A、第二端 B | AB |

- 单端有标签的接触也纳入，不限于双端已定相记录。
- 有误差或不确定性的标签使用明确的标签观测概率/置信度模型，避免错误标签成为硬约束。
- 以上表格只是潜在来源项的说明；完整 likelihood 必须同时定义标签获得机制、观测类别、归一化与 exposure，不能删去混合项后直接沿用旧目标。
- 每条原始记录计数一次；聚合时保留无标签、部分标签、完整标签及相应置信信息，避免重复使用。
- 可靠 A/B 应具有明确的跨位点单倍型定义；孤立杂合 SNP 或局部 phase block 不自动等于全染色体一致标签。若只有局部定相，需另外处理 block 方向及 switch error。

### 最小验证实验

1. 在有较充分标签的数据上，预先按规则只向训练开放少量标签；其他接触仍作为无标签数据保留，接触集合和预算不随标签开放比例改变。
2. 设置完全 SNP-free 基线和预定的稀疏标签比例；比较单端标签与双端标签的作用。
3. 对同一标签数量，比较分散覆盖、局部聚集和长无标签区；加入标签错误及 phase-block switch 的敏感性实验。
4. 未向训练开放的标签仅用于隔离评估。若标签通过同一 phase block 的推断相互依赖，需定义 block 级隔离，避免把共享定相信息当成独立证据。
5. 预先冻结训练预算和选择标准。结构、标签预测、长程 copy 一致性分别报告；同一接触参与几何拟合而仅隐藏其标签时，结果属于标签预测评估，不是独立接触泛化。

### 工程边界

这是单独的 SNP-assisted 模式。未来实现需显式定义可供训练的标签来源及配额，并与当前 SNP-free 输入、schema gate、provenance 和结果标记分开。不能通过关闭当前 gate 把 phase 文件送入既有 SNP-free 路径。评估标签与 reference 仍须在候选坐标写出、hash 和固定后使用。

## 后续落实入口

开始任一方向时，先确定输入数据及其 copy 数/标签语义，再把相应最小验证方案细化为冻结协议。两种应用可以分别验证，暂不将“未知拷贝数 + 稀疏 SNP + 复杂重排”合并成一个首轮实验。
